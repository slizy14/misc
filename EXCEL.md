# Excel in Python

1. Virtuelle Umgebung erstellen und aktivieren
```bash
python -m venv .venv
source .venv/Scripts/activate
```

2. Externe Library installieren
```bash
pip install openpyxl
# oder requirements.txt anlegen und dann mit pip aufrufen
pip install -r requirements.txt
```
